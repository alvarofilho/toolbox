# Kubernetes schemas

Source: https://github.com/yannh/kubernetes-json-schema/tree/93153a1458e24e93f386c50f9980d584fcba574b/v1.35.0-standalone-strict

Kubernetes 1.35.0 standalone strict schemas, derived upstream from Kubernetes OpenAPI. Schema content is preserved with normalized formatting and loaded locally on demand. Run `node scripts/update-kubernetes-schemas.mjs` to refresh and review the upstream commit.
